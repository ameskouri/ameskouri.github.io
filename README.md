# Adam Meskouri, personal site

Live at https://ameskouri.github.io

Plain HTML, CSS and a little JavaScript; no build step.

- `index.html`: all the words and links on the page.
- `styles.css`: layout, type and colour.
- `main.js`: the three visuals, all drawn in the browser: the flow behind the name, the still spiral of the
  Harvard database's 2,806,605 points, and the knot of threads beside the contact rows. There are no video
  files.
- `assets/`: the headshot and the two affiliation logos.

## Editing

Change a file and commit it to `main`; GitHub Pages republishes the site within a minute or two.

- For a quick wording change, open `index.html` on github.com, click the pencil icon, edit the text between
  the tags, and commit.
- After changing `styles.css` or `main.js`, raise the `?v=` number where `index.html` loads them, so
  browsers fetch the new copy instead of a cached one.
